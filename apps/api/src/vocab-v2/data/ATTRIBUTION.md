# Vocabulary Coach V2 word-list attribution

Vocabulary Coach V2 includes the **New General Service List 1.2 (NGSL)** and
the **New Academic Word List 1.2 (NAWL)** by Charles Browne, Brent Culligan and
Joseph Phillips.

- Official project: <https://www.newgeneralservicelist.com>
- NGSL: <https://www.newgeneralservicelist.com/new-general-service-list>
- NAWL: <https://www.newgeneralservicelist.com/new-academic-word-list>
- License: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/)

The checked-in JSON is a normalized, machine-readable transformation of the
official learning-dictionary tables. It preserves the published rank, headword,
pronunciation, part of speech and easy-English definition and adds no proprietary
dictionary content.

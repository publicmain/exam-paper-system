## 0. 一句话结论

学生在早测里失分，主要不是因为读不懂，而是因为**要打字的题他们不写**。

## 1. 诊断

对该班全历史已判分作答按 `taskType` 聚合（每道题一直都存着这个字段，
但系统从未按它统计过）：

| 作答方式 | 题型 | 得分率 | 空着不答 |
|---|---|---|---|
| 选一个 | 判断题 / 段落匹配 / 单选 / 多选 | 58–67% | **6–12%** |
| 打字 | 句子填空 / 摘要填空 / 流程图 / 图表标注 | 28–53% | **36–51%** |
| 打字 | O-Level 短答（全卷） | **19%** | **64%** |

这是一个受控对照：**同一批学生、同一份卷子、同一篇文章**，唯一的差别
是作答方式。所以「O-Level 常年 13–25%」的根因是输入门槛，不是题目难度，
也不是阅读能力。

两个佐证：

- 交卷确认页**本来就会**列出未答题号。学生看见「还有 5 题未答」照样交卷，
  说明不是忘了，是不打算写。多加提醒无效。
- 个案：刘钇村 60 天内所有需打字题型 **100% 空白、0 分（63 题）**，
  而选择型题目他都做，得分 15–50%。这不是能力问题。

### 1.1 参与度

花名册 33 人，近 5 周每周实际作答 20–28 人，从未满员。约 5–13 人长期不参与。

### 1.2 生词本（1.x 已上线功能）复盘

- 100 次复习、15 名学生，**全部发生在早测当天**，非早测日零复习
- 点词查义只有 1 人用过 —— 根因查明：`TappablePassage` 只挂在
  「历史成绩详情页」，**考试当中的原文根本不能点**，学生要用它得
  交卷 → 进历史 → 点开某一场 → 才够得着，四层深

## 2. 2.0 做了什么

按「学生影响 × 风险」排序，只做有证据支撑的。

### P0 关掉 AI 判分（铁律收口）

`lockOne` / `submitPractice` / `regradeSession` 三处原本无条件把
`evaluator` 传进 `autoGradeScripts`。线上 `ANTHROPIC_API_KEY` 是真实
密钥，所以每个考试日 09:00 都会对每份含长参考答案短答的提交发真实
请求 —— 挡住它的只是「额度是空的」，不是任何开关。一旦充值就会静默
开始自动判分，而本校铁律是零 Anthropic 调用。

新增 `MORNING_QUIZ_AI_GRADING`，**默认关闭**：MCQ 照常即时判分，短答
`deferAi` 进人工队列。要恢复设 `=on`，不必改代码。

### P1 降低输入门槛

O-Level 主观题从单行 `input` 改为 `textarea`：2 分题 3 行，8 分摘要题
8 行并实时显示词数（超 80 只提示不拦截，扣分仍由老师按 SEAB 口径判）。

判据是 `uiKind === 'olevel_short_answer' || marks >= 2`，已对全部 1114 道
历史题验证：雅思全部是 1 分且无 `uiKind`，一道不受影响。

### P2 技能画像

`SkillProfileService` + 两个接口：

- `GET /morning-quiz/skill-profile?name=` — 学生自查，公开，复用
  `history-by-name` 的姓名解析与限流
- `GET /morning-quiz/classes/:id/skill-profile` — 教师端，`canActOnClass` 鉴权

**关键设计：得分率和空白率必须并列，不能只报一个数。**
只看得分率会把「不会做」和「懒得打字」压成同一个红格子，而这两者的
教学干预完全不同 —— 前者要重讲解题方法，后者要先弄清学生为什么不动手。

学生端卡片进 `/my-history`（在逐场成绩之前，因为它回答「我该练什么」）；
教师端页面 `/morning-quiz/classes/:id/skills`，入口在排期页每行。

## 3. 明确**不做**的事，以及原因

### 考试中开放点词查义

能一举解决「点词功能没人用」，但会改变考试性质 —— 学生可以逐词查。
早测虽是形成性评价，把它变成开卷词典练习是另一个决定，**必须由老师
定，不能由工程侧顺手改**。

替代方案（未实施，留待决定）：把交卷后的「重读原文」路径从四层压到一层。

### 点原文自动填空

同一类问题。填空题的指令本来就是 "Choose NO MORE THAN TWO WORDS
**FROM THE PASSAGE**"，答案就在原文里，点选填入不会泄漏答案，还能把
拼写噪音从阅读测量里剥离。但它确实降低了难度，且真实雅思要求手打。
**是教学取舍不是工程取舍**，留给老师定。

### 降低 O-Level 题目难度

诊断表明难度不是主因。在输入门槛解决之前调难度，会把两个变量搅在一起，
之后再也说不清哪个起了作用。**先只动一个变量，观察一到两周**。

## 4. 怎么验证 2.0 有没有用

一周后重新跑技能诊断，看这三个数：

1. **O-Level 短答空白率**（基线 64%）—— 多行输入框如果有用，这个数该降
2. **雅思填空类空白率**（基线 36–51%）—— 未做干预，作为对照组应基本不变
3. **非早测日复习次数**（基线 0）—— 到期徽章如果有用，该出现非零

第 2 项是对照组，这是判断第 1 项的变化是不是干预造成的唯一办法。
如果两组一起降了，那是别的原因（比如换了卷子），不能记在多行输入框头上。

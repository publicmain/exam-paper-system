# 我的单词：统一词汇系统验收矩阵

更新日期：2026-09-02

本文档以最终确认的简化方案为准。学生端只有一个入口「我的单词」，每日新词、阅读收词、主动搜索和老师布置共用一份个人词汇数据。不设系统复习任务，不设「今天考/明天考」，不再维护一套平行的旧生词本流程。

## 一、一个入口、一份数据

| 验收项 | 实现规则 | 状态 |
| --- | --- | --- |
| 统一入口 | 首页只显示「我的单词」；旧词汇教练、旧生词本及旧测试路由重定向统一页 | 完成 |
| 统一个人词汇 | `StudentVocabularySense` 保存词义、来源、是否在我的单词、是否移出、实际学习次数等 | 完成 |
| 词义级去重 | 按「单词＋词性＋词义」识别，避免同义项被不同来源反复发送 | 完成 |
| 旧数据兼容 | 幂等迁移脚本保留已有来源、语境和掌握状态 | 完成（上线时执行） |
| 移出不丢历史 | 学生移出后不再显示为待学，但保留学过与来源记录，可手动重新学习 | 完成 |

## 二、每日新词

| 验收项 | 实现规则 | 状态 |
| --- | --- | --- |
| 新词来源 | 老师当日强制布置优先；自动补足仅从学生难度对应的 NGSL/NAWL 词表中选取 | 完成 |
| 全局去重 | 候选前排除该学生曾以任何来源、任何状态拥有过的词义，包括已掌握和曾换掉的词 | 完成 |
| 换词 | 「我会了，换一个」在原位置换入从未出现的合格词；旧词记为已会且不再自动推送 | 完成 |
| 老师强制例外 | 老师明确强制布置可重新激活已会或已移出词；这是唯一自动去重例外 | 完成 |
| 学习阶段不出考题 | 学习页只保留词义/发音与语境/用法两个教学屏，不出中译英、填空或四选一 | 完成 |
| 实际学习口径 | 只有点击「学完这个词」才计入累计学习；换词和稍后不计入 | 完成 |
| 断点恢复 | 每日学习会话和每个词的进度由服务端保存，刷新、退出或换设备可继续 | 完成 |

## 三、每日正式单词测试

| 验收项 | 实现规则 | 状态 |
| --- | --- | --- |
| 自动生成 | 当天所有新词处理完成后，服务器自动冻结正式测试，学生自动回到首页 | 完成 |
| 试卷词集 | 严格等于当天实际学完的词；不包括换掉、已会或稍后再学的词 | 完成 |

## 七、内容质量与阅读发布

- 五档难度、25 篇原创文章、250 道题。
- 每道题保存答案、解释、原文证据或评分要点。
- 发布前检查题量、选项结构、答案格式、证据和目标单词。
- 新增对当周文章、题干及数据库历史内容的语义相似度门槛；过度相似则阻止发布。
- 已经学生作答的内容通过版本冻结，不得静默替换。
- 系统通过可执行质量门槛降低错误和重复概率；不做「绝对永远无错」的不可验证承诺。

## 八、双端体验

- 手机端使用底部抽屉、单列卡片和至少 44px 触控目标。
- iPad/桌面端使用宽屏网格和更宽内容区，不将页面挤成手机窄栏。
- 学习页、正式测试、自主练习、阅读查词和教师看板共用简洁的 iOS 风格。
- 结果、待办、保存失败和空数据均有可见提示。

# P0 实测报告 — ECDICT 词典可行性（生词本硬闸门）

> 日期：2026-07-31 ｜ 对应 [vocabulary-notebook.md](./vocabulary-notebook.md) §6 P0
> 判定标准：**查得率 < 90% 则方案回炉**
> 结论：**✅ 通过，且余量很大 —— 词形 98.6% / 词次 99.4%，建议进入 P1**

## 1. 实测方法

- **语料**：生产库全部文章（`snapshotContent.passage`，按 `passageTitle` 去重）= **69 篇 / 45,409 词次 / 6,930 词形**
- **词典**：ECDICT `ecdict.csv`（MIT，**770,612** 条）+ `lemma.en.txt`（102,034 条）
- **分词器**：与真实点词功能将采用的同一套（小写化、保留内部连字符与撇号、剔除含数字 token）
  —— 因此这里测出的覆盖率**就是学生真实点击会遇到的覆盖率**
- **解析链**：直接命中 → exchange 字段反查变形 → lemma 表还原 → miss

## 2. 覆盖率结果

| 解析方式 | 词形数 | 占比 |
|---|---|---|
| ① 直接命中 | 6,629 | 95.7% |
| ② exchange 反查 | 1 | 0.0% |
| ③ lemma 表还原 | 1 | 0.0% |
| ✗ 查不到 | 299 | 4.3% |

**基础查得率：词形 95.7% ／ 词次 98.7%**

再加入两条简单规则（**所有格剥离 `Singapore's→singapore`** + **连字符拆分 `public-housing→public/housing`**），
救回 204 词形 / 325 词次：

| 最终 | 查得率 |
|---|---|
| **按词形（type）** | **98.6%** |
| **按词次（token，学生真实体验）** | **99.4%** |

## 3. 释义质量

已解析的 6,631 个词形中：

| 指标 | 覆盖 |
|---|---|
| 有中文释义 | **100.0%** |
| 有音标 | 81.3% |
| 有考试标签 | 54.1% |
| 其中标注 **IELTS** | **1,839 个词** |

标签分布：`gk=2087 cet6=1848 ielts=1839 ky=1830 cet4=1767 toefl=1600 zk=1242 gre=796`
→ 可以直接在点词卡上标「**这是雅思词**」，也可用于判断该词值不值得入生词本。

### 变形词抽查（学生点到变形时实际看到的内容）

| 点击的词 | 词典返回 |
|---|---|
| went | `go的过去式` |
| **coaxed** | `哄, 用好话劝说( coax的过去式和过去分词 ); 巧言骗取; 哄劝, 劝诱` |
| **crumpled** | `弄皱了的, 被扭弯的, 弯曲的` |
| thundered | `打雷( thunder的过去式和过去分词 ); 发出隆隆声` |
| knitted | `knit的过去式和过去分词` |
| children / better / worst | 均正确 |

**关键证据**：`coax` 和 `crumpled` 正是 7/30–7/31 判分中学生答错的两个词义题目标词。
词典给出的「哄、用好话劝说」「弄皱了的」**恰好就是 mark scheme 的标准答案**
（gently/patiently persuade；creased and wrinkled）。
→ 这个功能确实命中了学生真实的失分点，不是想象出来的需求。

## 4. 查不到的 95 个词 —— 全部属于"本来就不该查词典"的类别

| 类别 | 数量 | 样例 |
|---|---|---|
| 新加坡/本地文化词（**文末 Glossary 已解释**） | 26 | hdb(33), kueh(14), tampines(13), pandan(10), kelong, kompang, tekka, ubin, newater |
| 人名 / 专有名词 | 63 | samad, chandran, ventris, ebbinghaus, faridah, daniyal, honorton |
| 其他 | 6 | kintsugi(日语借词), kopi-o, f-a-s-t-i-d-e-o-u-s（拼写比赛文中的逐字母拼写） |

**没有一个是"常用英语词但词典没收"** —— 说明缺口不是词典质量问题，
而是专名与本地词，这两类本来就由文末 Glossary 承担，无需词典兜底。

## 5. 下发体积（离线可行性）

以《The Old Radio》为样本：**304 个词形 → 298 条可下发词条 → JSON 约 22.0 KB**（未压缩，仅取首条释义）。

→ 随试卷一并下发完全可行；gzip 后约 6–8 KB，比一张图片还小。
**零 API、零延迟、断网可用**的方案成立。

## 6. 重要工程简化（对 P1 的直接影响）

`exchange` 与 `lemma` 两条解析路径**各只命中 1 个词形** —— 因为 ECDICT 的 77 万条目
已经把 `went` / `shattered` / `coaxed` 这类变形**当作独立词条直接收录**了。

**结论：P1 不需要实现词形还原引擎。**
只需：`直查` →（失败时）`剥离 's` →（失败时）`按连字符拆分`。三行逻辑拿到 99.4%。
`lemma.en.txt`（2.2 MB）**可以不引入**，P1 复杂度显著低于 PRD 原估。

## 一、登录与今天的课

### 1. 普通登录

- **地址**：`/login`
- **该看到**：两个输入框，标签是**「姓名」与「密码」**
  （字段叫密码，填的就是那八位数字）。填 `验收学生林思远` 与 PIN，
  提交后落到 `/today`，页头认出你的名字。
- **已知可行**：这一步我已经用同一个端点、同一种请求形状跑通了
  （201，认出 `s12f_acceptance_student`）。
- **失败**：提示「找不到这个人」或「PIN 不对」；或者需要点那个免密按钮才进得去；
  或者地址栏里出现了姓名 / studentId。
- **留痕**：有 —— 服务端会更新 `lastLogin`。

### 2. 看今天那一课（**先别点开始**）

- **地址**：`/today`
- **该看到**：三段任务都是「未开始」—— 阅读 `todo`（10 题）、
  背词 `0 / 21`、补段 `0 / 5`；今天的篇目标题是
  **《The Rooftop Garden, Two Years On》**。
- **已知**：主页的**「连续学习天数」会显示 0**，不是 13。
  这不是缺陷，是夹具的一处真实度缺口：连续天数只认
  `readSource ∈ {student, teacher}` 的日子，而历史任务行写的是 `lesson`。
  生词本那个连续天数是对的（**14 天**）。不影响任何一步的验收。
- **失败**：显示「今天的课程还没有发布」；或者三段里任何一段已经有进度
  （那说明当天状态被别人碰过，整份验收作废）。
- **留痕**：有 —— 打开课程页就会创建当天的任务行。**这是设计如此**：
  第一个创建它的人应该是你。

### 3. 开始阅读

- **地址**：`/lesson/reading`
- **该看到**：卷首一整段原文（五个自然段，讲屋顶菜园），下面十道题分组
  排列：TRUE/FALSE/NOT GIVEN 三道、句子填空三道、配对两道、简答两道。
  TFNG 那三道渲染成单选按钮，不是文本框。
- **失败**：原文没出来只有题目；题目挤成一团没有分组；TFNG 变成了裸文本框；
  或者页面报错。
- **留痕**：有（会创建答卷行）。

### 4. 刷新 / 断点续答

- **地址**：`/lesson/reading`（原地刷新）
- **该看到**：先随便答两三题，然后**刷新页面**。刚才填的答案还在，
  倒计时接着走，没有回到「今天的课」重来一遍。
- **失败**：答案清空；或者被弹回 `/today`；或者要求重新登录。
- **留痕**：有（答案会随手存）。

### 5. 点原文里的生词

- **地址**：`/lesson/reading`
- **该看到**：在原文最后一段找到 **`blossom`** 这个词，**用手指点一下它**
  （不是长按选中，就是轻点）。底部弹出词卡，显示这个词的音标和中文释义。
- **失败**：点了没反应；点了变成拖动选中一片文字；弹出的是别的词；
  或者词卡里没有释义。
- **补充**：`blossom` 是特意留的 —— 它在词典里、但**不在**这个账号的生词本里，
  也**不是**任何一道题的答案。顺手试试点一个属于答案的词，词卡应该**拒绝**
  给你（防作弊）。
- **留痕**：无（查词本身不写库）。

### 6. 看词典数据

- **该看到**：词卡上有音标、词性、中文释义；不是「查不到这个词」。
- **失败**：空白、只有单词本身、或者显示报错。
- **留痕**：无。

### 7. 加进生词本

- **该看到**：词卡上有「加入生词本」。点一下，出现「已加入」之类的回执。
  这一步会把 `blossom` 连同**你点它的那句原文**一起存进生词本。
- **失败**：按钮点了没反应；提示需要登录；或者回执说成功但第 20 步在
  生词本里找不到它。
- **留痕**：有。

### 8. 用词卡填答案

- **地址**：`/lesson/reading`
- **该看到**：先点一下**第 4 题**（句子填空，「The first beds were built from
  wood taken from an old ______.」）的输入框，让它获得焦点；再去原文里点一个词。
  词卡上应出现「填入第 4 题」。点它，那个词进到第 4 题的输入框里。
  如果第 4 题已经有内容，按钮会变成「追加到第 4 题」。
- **失败**：词卡上根本没有「填入第 N 题」；点了没填进去；或者填到了别的题上。
- **留痕**：有（答案会存）。

### 9. 答完并交卷

- **该看到**：十道题都作答（可以故意错几道，后面看结果更有意思），
  点交卷，出现确认弹窗，确认后跳到阅读结果页。
- **失败**：交卷按钮不可点；确认后停在原地；或者报错。
- **留痕**：有 —— **这一步不可逆**，答卷会最终提交。

### 10. 看阅读结果

- **地址**：`/lesson/reading/result`
- **该看到**：选择题部分立刻有分（自动判分）；主观题显示「等老师判」之类
  的状态而**不是**假装已经判好；页面给出继续学习的入口。
- **失败**：显示一个凭空算出来的百分比；或者主观题也被算了分；
  或者结果页空白。
- **留痕**：无（只是展示）。

## 二、词汇与正式测试

### 11. 进入课程内的词汇

- **地址**：`/lesson/vocab`
- **该看到**：从结果页点「继续」进来，出现今天要学 / 要复习的词卡，
  每张卡有例句，例句里那个词被挖空或高亮。
- **失败**：显示「今天没有要背的词」（这个账号有 21 个词今天到期，
  不该是空的）；或者卡片没有例句。
- **留痕**：有。

### 12. 把词卡做完

- **该看到**：逐张翻卡、逐张评分（「记不清 / 有点难 / 记住了 / 很简单」）。
  评分后有回执告诉你下次什么时候再见到它。做完进度条走满。
- **失败**：评了分进度不动；或者同一张卡反复出现出不去；或者回执说
  「答得太快，这次不算」而你明明看了几秒（那是防秒过机制，正常；
  慢一点重试）。
- **留痕**：有 —— 会写复习流水，并改变这些词的下次复习时间。

### 13. 进正式单词测试

- **地址**：`/lesson/test`
- **该看到**：课程页把你导到正式测试；出现四道题的卷子。
- **失败**：提示「今天的词不够开一场测试」（这个账号有 19 个「教过且到期」
  的词，远超过 4 个的下限，出现这个提示就是缺陷）。
- **留痕**：有（会创建当天的正式测试记录）。

### 14. 确认四种题型都在

- **该看到**：四道题应当覆盖 —— **拼写**（给首字母，自己把词打出来）、
  **原句填空**（挖空的例句选词）、**看词选义**、**看义选词**。
- **失败**：四道全是选择题（拼写和填空一道都没有）；或者同一种题型出现两次
  而另一种没有。
- **留痕**：无（题目是当场生成的）。

### 15. 确认没作答的题不泄漏答案

- **该看到**：在**还没提交**的时候打开浏览器的「查看网页源代码 / 检查」，
  或者干脆在页面上翻一翻 —— **正确答案不该出现在任何地方**。
  选择题的选项顺序里也不该有明显规律。
- **失败**：在页面 DOM 或网络响应里能直接读到正确答案。
- **留痕**：无。

### 16. 测试中途刷新

- **该看到**：答两道后刷新，已答的还在，测试没有重新开始，也没有被判作废。
- **失败**：进度清零；或者被判「已交卷」。
- **留痕**：无（除已有的答题记录外）。

### 17. 交卷并看分数

- **该看到**：提交后立刻出现分数（例如「答对 3 / 4」），并能看到每题对错。
- **失败**：分数与你实际答对的数目对不上；或者交卷后停在原地。
- **留痕**：有 —— 分数会永久写进当天的测试记录。

### 18. 今日总结

- **地址**：`/lesson/summary`
- **该看到**：今天三段（阅读 / 背词 / 补段）的完成情况汇总。
- **失败**：完成度与你刚才实际做的对不上。
- **已知**：连续学习天数仍会是 0（原因见第 2 步），不算失败。
- **留痕**：有。

## 三、四个独立页面

### 19. 历史成绩

- **地址**：`/scores`，再点进 `/scores/:submissionId`
- **该看到**：**12 份历史阅读答卷**（含今天刚交的那份就是 13 份），
  篇目名各不相同，日期从昨天一路往前排。其中 **10 份已判**（分数从 0 到 8
  都有），**2 份诚实地显示「等老师判」**。随便点开三份看详情：
  逐题的题干、你当时的答案、正确答案、得分、老师评语都在。
  **已经判完的历史卷子必须一直看得到** —— 它们不会因为今天做了新卷子而消失。
- **失败**：列表是空的；只看得到今天那一份；待判的那两份被显示成 0 分；
  或者详情页报错 / 缺字段。
- **留痕**：无。

### 20. 生词本 / 自由练习 / 自测

- **地址**：`/vocab`、`/vocab/practice`、`/vocab/selftest`
- **该看到**：
  - `/vocab`：**50 个词**（加上你第 7 步加的 `blossom` 就是 51），
    状态分成未开始 / 学习中 / 复习中 / 已掌握四档，每条有音标、释义、
    来源篇目、语境句、下次复习时间。找到 `blossom`，它的语境句应该
    就是你点它的那一句。
  - `/vocab` 的统计：已掌握 8 · 学习中 32 · 待开始 10，待复习 21，
    累计复习 198 次，连续 14 天，**今天复习 0 次**（你还没开始）。
  - `/vocab/practice`：能翻卡、能跳过、能评分、评完能撤销。
  - `/vocab/selftest`：能开一份自测，做完给出「答对 N / M」。
- **失败**：词数明显对不上；`blossom` 不在里面；跳过或揭开答案就把词
  「用掉了」；撤销之后下次复习时间没回到原样。
- **留痕**：评分与自测会写复习流水（撤销能还原）；移除词是永久的。

### 21. 错题本与错题重练

- **地址**：`/mistakes`、`/mistakes/practice`
- **该看到**：
  - `/mistakes`：**20 条错题**，题型五花八门（TFNG / 配对 / 填空 / 简答 /
    选择），收录原因分三种（这类题反复错 / 词义没掌握 / 长答题），
    其中 4 条已经销账、16 条还没有。每条有题干、你当时的答案、正确答案、
    老师评语、重练连对次数。
  - 挑一条**练一次**：`/mistakes/practice` 里作答**之前**页面上不该出现
    任何答案材料；自评之后回到列表，那条的重练次数 +1。
  - 挑一条**销账**，它移到「已经弄懂」；再**恢复**它，回到未销账。
- **失败**：错题本是空的；作答前就能看到答案；销账后那条被删掉了
  （应该只是改状态）；或者恢复不回来。
- **留痕**：重练结果与销账状态都会永久写库。

### 22. 账号页

- **地址**：`/account`
- **该看到**：你的名字、班级、以及退出登录。
- **失败**：显示别人的名字；或者页面里出现了 studentId / 令牌之类的东西。
- **留痕**：无。

### 23. 退出并重新普通登录

- **地址**：`/account` → 退出 → `/login` → 再登一次
- **该看到**：退出后回到登录页，本地存储被清干净；用同样的姓名 + PIN
  能再登进来，落到 `/today`，**今天的进度还在**（不会因为重新登录就重置）。
- **失败**：退出后还能访问 `/today`；或者重新登录后今天的课变回「未开始」；
  或者需要用免密按钮才进得去。
- **留痕**：有（又一次 `lastLogin`）。

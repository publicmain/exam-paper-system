## 2. 目标学生产品（唯一定义）

**账号制、全天可进入的英语学习 App。**

### 2.1 正式课程主流程（线性七步）

```
账号登录
  → 今天的课程
  → 阅读
  → 学习本次单词
  → 正式单词测试
  → 今日总结
```

这条链是**唯一的正式路径**。它必须满足：

- **不依赖扫码**。没有二维码、没有扫码令牌、没有大屏。
- **不依赖考勤**。学生没有考勤行也能上完整节课。
- **不依赖姓名查询**。任何「输入姓名查看」的入口都不在这条链上。
- **不依赖 URL 里的 studentId**。地址栏里出现的身份参数一律不是身份。
- **全天可进入**。没有「已经过了作答时间」，没有下午的第二作答窗。

### 2.2 同一外壳内的四个独立页面

| 页面 | 它是什么 |
|---|---|
| 历史成绩 | 学生自己的成绩记录，**账号制**，不输姓名 |
| 生词本 | 自由练习区，与正式课程的词队列**明确分开** |
| 错题本 | 同上 |
| 账号设置 | 改密码、看自己是谁、退出 |

它们与主流程共用同一个 App 外壳（同一套导航、同一个身份、同一种返回
语义），但**不属于**七步链 —— 从它们进出不推进课程阶段。

### 2.3 身份契约

1. 登录后，身份**只来自服务端验证过的学生令牌**。
2. canonical URL **不携带姓名或 studentId 作为身份**。
3. 页面**不得**从 `localStorage` 的姓名键推断身份。
4. 令牌失效 → 回到登录页，**不是**回到姓名输入页。

## 3. 教师后台（保留，但不决定学生端）

教师组卷、题库、判分、班级管理、排课、看板、历史数据、家长门户
**继续保留**，行为不变。

**边界规则**：教师后台的页面结构、路由、导航和文案，**不得**决定学生
App 的页面结构。今天违反这条的地方（学生刷新后落进教师时代的学生外壳、
阅读页的错误兜底跳到 `/student`）见
[student-route-inventory.md](./student-route-inventory.md)。

## 4. 这份契约怎么用

- 任何新页面先回答：它在七步链上，还是四个独立页面之一，还是教师后台？
  三者都不是 → 不建。
- 任何跳转先回答：目标页面属于同一个 App 外壳吗？不属于 → 不跳。
- 任何测试先回答：它断言的是这份契约，还是旧产品的行为？是后者 →
  它在保护错误的东西，见 [legacy-retirement-map.md](./legacy-retirement-map.md)。

# 每日英语 App 完整化 · 设计定稿（2026-11-05）

来源：Claude 稿 + GPT 稿 + 代码盘点 + GPT 挑刺稿（`.local/research/blueprint/out/`，不入库）+ 叶老师 11-05 拍板。9 月升级方案（F01–F09）作废，只作历史参考。

## 1. 目标
学校自己的英语 App：16:00 那节课（约 60 分钟）+ 8:30 早读纸笔默写 + 课后，把词汇、阅读、听、说串成闭环。学生真学到；老师一眼看出该找谁；老板几乎不操心。吸收 8 个开源项目的长处，但只有一套任务、一套词库、一套记录。

## 2. 老板拍板（硬规则）
1. **每天必做仍只有三件**：阅读、学新词、单词测试。听、跟读、造句、拼写打字进「加练」选做（认真做了能进徽章）。
2. **旧词按记忆规律复习；单词总量固定，复习多就少推新词。**
3. **错题本完整上线**：自动收、隔几天要求重做、做对才消；**重做并进当天任务**（阅读错题接在当天阅读后面，单词错题放进单词测试），首页仍三件事。
4. **口语要自动发音打分**（微软 Azure 发音评测）；录音授权 = 学校统一同意，App 内说明用途。
5. **早读默写后，所有班老师都在 App 里回填错词 / 缺考**，App 按真实默写结果安排复习。
6. **目前不花任何钱**：不开任何新付费服务；Azure 只用免费额度并在代码里硬封顶（额度用完当月停用，绝不产生账单）；文章朗读用本机 Piper 生成；测试用本机演示环境，不新开 Railway 测试站。
7. 沿用：零 Anthropic API；学生数据和姓名不给 GPT；上线要老板说「上线」；学生可见文字逐字审；糊弄的不算。

## 3. Claude 定的事（老板可推翻）
- 「我会了 / 换词」保留，但只记为「自报会了」，不再等于掌握（现在 `learning-card.ts:27` 直接给 stage 8）。
- 考试周、假期、请假：老师/管理员可把某班某些日期标成「停课日」——不排新任务、不算欠账、不断连续学习，已有记录保留。
- 默写回填的「未录入」= 未知，不当全对，也不更新该词调度。
- 错题「做对才消」= 隔天以后独立做对（不看提示）1 次即消；当天订正不消。错题重做每天最多 3 道阅读 + 3 个单词，超出的顺延。
- 加练区的记录只存结果（对错、是否提示、用时档），不存按键轨迹。

## 4. 证据语义（所有模块共用，P0）
每次作答记录这几种之一，互不覆盖：
| 类型 | 含义 |
|---|---|
| `practice_first` | 学新词/加练时第一次作答 |
| `practice_retry` | 当轮订正、提示后重答 |
| `formal_first` | 正式单词测试/阅读交卷的首答（唯一，不可覆盖） |
| `paper_dictation` | 老师回填的早读默写结果（对/错/缺考；未录入不写） |
| `mistake_redo` | 错题重做（隔天、无提示才计「消」） |
| `self_report` | 学生自报会了 / 换词 |
| `pronunciation` | 发音评测结果（第 4 期） |
调度（FSRS）只吃 `formal_first`、`paper_dictation`、`mistake_redo`；「掌握」统计只看这三类，不看 `self_report` 和练习。

## 5. 分期
### 第 1 期：地基 + 第一批看得见的（约 3–4 周）
- **1A 证据与并发**：首答保护（事务内条件更新）、交卷状态抢占、提交幂等；落第 4 节证据字段；「我会了」改记 `self_report`。现状风险见 `vocabulary-v2.service.ts:2666、2721`（盘点稿）。
- **1B 学新词加「遮词回忆拼写」**：看完词卡后遮住单词，凭中文+发音拼出来；错了逐步露前缀（最多露到差一个字母），记录错在第几个字母、错成什么；仍是「学新词」同一个任务。iPad 输入框关自动纠错/大写/拼写检查，处理输入法组合输入。依赖 1A。
- **1C 零 API 硬门**：所有 AI 客户端（Anthropic/OpenAI/图片）默认拒绝，只有显式白名单开关才放行；公共翻译外发（MyMemory/Google）默认关；有测试证明默认零调用。
- **1D 老师「今天该找谁」**：每班一页，聚合已有事实——没做完、待批、低分、被警告过糊弄；每条能点进来源。不新造指标。
- **1E 停课日**：老师/管理员按班标日期；排任务、欠账、连续学习、周报分母都认它。
验收：本机演示环境五档各走一遍真实链路；旧 iPad 尺寸 + 软键盘；弱网重复提交不重复记分；现有徽章「认真做才算」不退化；三端测试和 `npm run build -w @app/api` 全绿。
### 第 2 期：记忆闭环（约 3–4 周）
FSRS 接进 V2 正式词测（总量封顶，复习替换新词）；错题本完整上线（并进当天阅读/词测）；默写回填（全部班，打印清单锁定为实际学完的词）；测后反馈（原答、正解、出处、之后再考）；周报升级（首考、延迟记忆、默写正确率分开）；默写纸标「班里常错拼法」。
### 第 3 期：听读与加练（约 3 周）
文章逐句朗读（Piper 本地生成、按句时间轴、慢速/循环、版本化音频 URL）；交卷后「答案出处」原文高亮；加练区：拼写打字、词→短语→句子造句阶梯、跟读；可选 word-atlas CC BY 插图（逐张审、署名）。
### 第 4 期：口语评分（约 2–3 周）
录音（App 内用途说明）→ Azure 发音评测免费档（月度硬封顶、超额停用、零账单）→ 逐词分 + 老师抽听；录音评完短期保存后删除。开工前核实免费额度与条款。

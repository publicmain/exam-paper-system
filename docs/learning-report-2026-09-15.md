# 学习周报 + 后台新建账号 · 2026-09-15

叶老师 2026-09-15 要一个「后台直接看到所有想要的信息」的地方，给自己和学校领导用；
领导用一个总的管理员账号登录。本文是这次改动的说明、验证证据、上线清单和回滚方式。

**代码在分支 `weekly-report-2026-09-15`（worktree `.local/wt/weekly`，从 main `9325452` 切出）上，
没有推送、没有部署、没有数据库迁移。**

## 1. 做了什么

### 学习周报（教师后台 `/learning-report`，导航「学习周报」）

打开就是本周，能按周往回翻、选全部班级或某个班（选择记在网址里，链接发给别人打开是同一个视图）：

- **总数**：在读学生、做过至少一项、阅读完成率（交了 / 应交）、单词测试次数、整周没做（周没过完时写「本周到目前一项没做」）；
- **每天**：交了阅读 / 应交、阅读平均得分率、学完当天新词、单词测试人数与平均分；
- **各班 / 各难度档**：各难度档按那份卷子的档位算（周中改过档的学生，卷子各归各档）；
- **需要跟进**：整周没做、阅读平均低于 30%、交了阅读单词一个没学、单词测试 0 分、还没选难度档；点名字跳到逐人表并展开；
- **逐人逐天**：每格上一行是阅读（得分率 / 待判 / 没交 / 没做 / —），下一行是单词（词✓、词3/10、测90）；点名字看每天明细（卷子名、交卷时间、分数、单词）；
- **导出 Excel（CSV）**、**打印 / 存 PDF**。

接口 `GET /learning-report/week?weekStart=&classId=`，只读。权限：管理员 / 班主任全校，任课老师只看自己教的班（别人的班 403）。

### 后台新建教职工账号（「管理 → 用户 → 新建账号」）

以前这一页只能改角色、停用、重置密码，建不了新账号。现在管理员可以建老师 / 班主任 / 管理员
（学生仍然只能在学生端自助注册）。接口 `POST /admin-rbac/users`，管理员专用：
邮箱去空白转小写、重复（不分大小写、并发也算）回 409；密码至少 8 位、只存 bcrypt 摘要，
响应和审计里都没有明文；建号和审计在同一个事务里。

### 顺手改的

- 导航里的「完成度」换成「学习周报」；`/lesson-board` 还在，页头写明「只看今天」并链到周报。
  （那一页服务端一直只取今天的数据，URL 里带日期也没用。）

## 2. 口径（`apps/api/src/learning-report/weekly-report.ts`，单测钉死）

| 名词 | 是什么 |
|---|---|
| 交了阅读 | 学生自己（或老师代）最终交卷；系统到点收卷不算；等老师批的算交了、没有分数 |
| 应交 | 已经过去的、分配给他的阅读 —— 直接用学习总表的 `assignedReadingFor`（入班以后、按那天的档位、取消的场次没交不算）；今天还没交不算欠 |
| 阅读得分率 | 只算已批完（marked / returned）的卷子 |
| 同一天交了两份 | 改档后按新档把当天卷子又做了一遍：取最后交的那份 |
| 整周没做 | 这周有应交的阅读，但阅读、学完新词、单词测试一样都没做（学了一部分词算做了） |
| 不计入 | 老师测试号、用户验收账号（`DEMO_ACCOUNT_IDS`，不配时默认这两个）、`p1_qa_acc_*`、QA 班、名字以【测试】开头的班；这周最后一个有课日之后才注册的学生 |

## 4. 上线清单（每一步都要叶老师点头）

1. **推前**：`npm run build -w @app/api`；确认没有发布内容的进程在跑。
2. 把 `weekly-report-2026-09-15` 合进 `main` 并推送 → API 与教师端自动部署。**没有数据库迁移。**
3. （可选）Railway API 服务配 `DEMO_ACCOUNT_IDS`（逗号分隔），不配时默认排除老师测试号和用户验收账号。
4. 管理员登录教师后台 →「管理 → 用户 → 新建账号」给领导建账号，角色选「管理员」，初始密码当面告诉对方。
   **这一步由叶老师自己操作**（建账号、设密码不由助手代办）。
5. 只读核对：打开「学习周报」，翻到 9 月 7 日那一周，应显示在读 33、做过 26、整周没做 7。

## 5. 回滚

- 代码：回退这次合并重新部署即可。
- 数据：周报只读；新建账号是新增行，不影响已有账号。要撤掉某个新建的账号，在「管理 → 用户」里停用。

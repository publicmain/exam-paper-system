# 小范围试点 —— 5–10 个学生，三天

> **状态：`PILOT_READY`。** 名单由你定 —— 这份文档只准备好流程。
> 阶段 12 **不是 PASS**，试点跑起来也不是。

## 一句话

把学生端放到 5–10 个**真学生**手上用三天，按他们撞到的东西修，
而不是继续在文档里推演架构。

## 账号：一人一个，不共用

**不要造一个共用账号。** 共用账号会同时毁掉两件事：谁看到了谁的数据
说不清楚，以及「这个学生今天学了什么」这条线整个断掉。

### 建账号（老师侧，每个学生一次）

1. 老师在教师端把学生加进**试点班级**并分配 `englishLevel`
   （`ielts_authentic` 或 `ielts_simplified` —— 按学生真实水平选，
   分错了他第一天就会觉得「这卷子不是给我做的」）。
2. 学生自己打开学生端 → **注册**（姓名 + 自设 6 位 PIN）。
   PIN 由学生自己设、自己记；老师端可以重置，但**任何人都不该替他设**。
3. 学生登录一次，确认页头认得出自己的名字。

> **不要**用登录页上那个「Staging：一键登录测试六号」——
> 那是夹具通道，用它等于没验到登录。

## 学生三天清单

每天大约 15–20 分钟。**按顺序做，别跳。**

### 第 1 天

1. 登录（姓名 + 自己设的 PIN）。
2. 在「今天的课」看一眼：**今天完成 0 / 2**（阅读 + 单词两段）。
3. 点「开始今天的课程」→ 做完阅读 → 交卷 → 看结果。
4. 继续「学习本次单词」——**每一张都是先教你**，看完点「我学过了」。
5. 进「正式单词测试」——**今天学了几个词就考几题**，开考前那句话会告诉你。
6. 看今日总结。
7. 随便点点「历史成绩」「生词本」。

### 第 2 天

1. 登录，重复第 1 天的七步。
2. 额外做两件：
   - 生词本里**搜一个词**，再按「学习中 / 待复习 / 已掌握」筛一遍；
   - 「考考自己」——**先选题量**（5 / 10 / 20 / 全部），做完看对了几题。
3. 如果有 iPad 或电脑，**用大屏再开一次**「历史成绩 → 某一份 → 查看原文」。

### 第 3 天

1. 登录，重复第 1 天的七步。
2. 额外做三件：
   - 中途**刷新一次**页面，确认答案没丢、进度没退；
   - 点「错题本」——它会说「暂未开放」，**这是故意的**，不是坏了；
   - 退出登录，再登回来，确认今天的进度还在。
3. 填反馈（下面那五个问题）。

---

## 反馈（三天结束时填一次，五个问题）

1. **哪一步让你卡住了？** 具体到你点了什么、屏幕上写了什么。
2. **有没有哪句话你看不懂？** 原样抄给我们。
3. **单词那一段，先教后考的顺序对不对？** 有没有出现「还没教就考」？
4. **手机 / iPad / 电脑上，有没有哪一屏排版是坏的？** 说清楚设备与那一页。
5. **明天你还愿意再用一次吗？为什么？**

> 反馈越具体越有用。「不好用」帮不上忙，「第二天的正式测试第 7 题只给了
> 一句挖空的英文，我不知道要填哪个词」立刻就能修。

## 立刻停止的条件

**出现下面任何一条，马上停掉试点、通知我们，不要让学生继续。**

| # | 现象 | 为什么是红线 |
| --- | --- | --- |
| 1 | **一个学生看到了另一个学生的数据**（姓名、成绩、生词本、错题） | 身份隔离破了。这是唯一一条「不用讨论、直接停」的 |
| 2 | **答案消失** —— 写过的答案刷新之后没了 | 学生的劳动被吞掉，信任一次性归零 |
| 3 | **学生卡在某一步过不去** —— 点了没反应、或永远停在同一屏 | 课上不下去，试点也就没有意义 |
| 4 | **分数对不上** —— 学生数得出自己对了几题，界面给的不一样 | 成绩是这个产品的信用底座 |
| 5 | **登录 / 账号错乱** —— 用 A 的 PIN 登进了 B，或退出后还能进 | 同第 1 条 |
| 6 | **重复答卷 / 数据看起来坏了** —— 同一天出现两份成绩、历史里冒出不属于自己的卷子 | 数据完整性问题会越滚越大 |

停止之后：记下**时间、学生、页面地址、屏幕上的字、上一步做了什么**。
这五样齐了才定位得快。

## 试点期已知的限制（不是缺陷，别当缺陷报）

| 现象 | 说明 |
| --- | --- |
| **错题本 / 错题重练进不去** | 整个功能在试点期**关着**。你以前的错题一条没删，只是暂时不开放；它也不计入今天的完成度 |
| **今天只有两段**（阅读 + 单词） | 同上。分母是 2 不是 3 |
| **词典查不到某些词**（例如 `grey`） | staging 的词典是一个很小的子集，**故意的**。界面会如实说「词典暂未收录这个词」——那是对的行为。生产上线前有单独的词典校验闸门 |
| **自测刷新会重新开一份** | 自测不计成绩，没做断点。**正式测试不受影响**，它照常断点续答 |
| **生词本没有分页** | 50 个词是一整页。词更多时会卡，试点后再做 |
| **生词本不能收藏 / 没有词详情页** | 试点范围之外 |
| **iPad / 电脑上的排版只做了关键几页** | 今天的课、生词本、练习、自测、课程学词、正式测试、历史成绩、结果页、账号 |

## 我们这边每天要做的事

1. **早上**：看一眼四个红线指标（跨学生数据、答案丢失、卡住、分数不符）。
2. **白天**：学生随时可以反馈；能当天修的当天修，改完只部署学生端。
3. **晚上**：把当天的反馈归类成「立刻修 / 试点后修 / 不修（说明理由）」。
4. **判分**：短答题仍然由人工在 marker 队列里判（`/api/marker/*`），
   **不走 AI 判分**（`CLAUDE.md` 的零 Anthropic API 铁律）。

## 试点结束之后

三天跑完 → 汇总反馈 → 决定：

- **继续扩大**（更多学生、更长时间）；
- **先修一轮再扩**；
- **回到 S12K 那份完整重建计划**（它没有作废，只是被试点插队了）。

**这三条都不等于阶段 12 PASS。** 阶段 12 要通过，仍然要走那条冻结的
人工验收流程 —— 试点只是让它更有可能一次过。

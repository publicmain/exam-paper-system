# 老师测试号：正式颁奖体验

2026-09-18，用户明确批准增加展示入口并上线。

- 正式学生端 →「我的徽章」→「老师测试专用」→ 选择奖章 →「体验颁奖」。主系列另有「连续体验四级」。
- 仅服务器 `/student-auth/me` 已核实的现有老师测试号身份可见。不按姓名、昵称、查询参数、浏览器缓存开关或 JWT 自解码判断；同名普通账号不可见。
- 16 枚均可预览，包括隐藏和最终奖章；普通学生原有隐藏规则不变。
- 和真实颁奖共用 `AwardCeremony`：全屏暗背景、真实 3D 模型、逐枚展示、继续、跳过全部、翻面和减少动态。不复制一套近似动画。
- 体验状态仅在组件内存中，退出或刷新即结束。明确标注仅展示，不解锁、不收藏、不修改成绩、学习计数、任务或真实通知。
- 入口本身不调用 API、不写 localStorage/数据库、不使用管理员授奖接口。原有页面正常同步不变；不能将 UI 可见性限制当作保护公开 3D 资源的后端权限。
- 真实颁奖通知在体验弹窗期间等待；关闭体验后照常显示，不会被预览的「跳过」消耗。
- 仅更改学生端；无数据库迁移、服务配置或后端业务变更。仍沿用现有 GitHub/Railway 发布流程及正式域名。

测试覆盖：精确身份与同名账号隔离、匿名/失联不可见、账号切换关闭、反复播放、四级队列、最后等待继续、加载失败可退出、零网络/持久化写入、预览与真实通知互斥；并回归学生端现有测试。
